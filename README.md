# calcutils

A simple utility package with basic arithmetic and statistics helpers, created as a lab exercise for publishing Python packages.

## Installation

```bash
pip install calcutils_henriette
```

## Usage

```python
from calcutils import add, multiply, average

print(add(10, 25))                # 35
print(multiply(3, 4))             # 12
print(average([10, 20, 30, 40]))  # 25.0
```
